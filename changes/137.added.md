A run that outlives its token no longer has to choose between a longer TTL and
re-executing everything it already did. `RunCredentials` refreshes in place: a
credential inside the skew window is replaced before the call is dispatched, and a
downstream rejection for expiry is answered with one mint and one retry rather than
a failed run. The window is configurable through `RefreshPolicy` because the clock
here and the clock at the far side are not the same clock.

Refresh is single-flight per audience, so a fan-out of concurrent tool calls costs
one mint and every waiter resumes on it. A cancelled refresh leaves nothing in the
cache. Unrelated audiences still refresh in parallel.

A refresh is not a renewal. Every mint re-derives the caller's authority through the
`Reauthoriser`, intersected with what the run already held, so authority can only
narrow — a directory answering with more scopes than the run started with does not
widen the run. Where the grant has been withdrawn, or the principal's own expiry has
passed, the run halts with `AuthorityRevokedError`: held credentials are dropped, no
further call is dispatched, and nothing is returned as though it were complete.

`suspend()` clears every credential, because a run waiting on a human approval gate
may resume days later and a token carried across that gap outlived the window it was
minted for. The authority is re-derived on resume instead.

The retry after a reactive refresh reuses the original idempotency key, so a
refreshed call cannot duplicate a side effect. A call made with no key is not
retried at all — it may already have landed, so it is reported as
`CredentialExpiredError(outcome="unknown")` rather than as a failure. An unreachable
mint is retried with jittered backoff, so many runs sharing one principal do not
refresh in unison, and is surfaced as `outcome="not_started"` without halting the
run.

`ExpiringCredential` and `ExpiringCredentialSource` join `tesserix_adk.core` as new
protocols; `tesserix_adk.tools.CredentialBroker` already satisfies both. Full
behaviour and its limits: [`docs/credential-refresh.md`](../docs/credential-refresh.md).
