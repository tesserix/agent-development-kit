A prompt change is now comparable against the version in production before it ships. `gate`
takes two `Measured` runs — the same dataset, replayed deterministically, scored by the same
judge — and returns a verdict, the movement in every declared metric, and a record keyed to
the candidate's digest.

`DEFAULT_POLICY` declares five metrics with per-metric regression thresholds: task success,
schema validity, judge score, p95 latency and cost per run. Cost is a gate rather than a
footnote, so a candidate that improves quality and raises spend fails until somebody records
a `Bypass` naming the metric, who took it and why.

It fails closed everywhere the comparison could mislead. A partly scored dataset raises
`EvalIncompleteError` carrying coverage, and no score is ever inferred for an example nobody
scored. A judge that moved since the baseline, or a candidate that changed the variables the
golden dataset supplies, raises `IncomparableEvalError` rather than reporting a difference
that is not the change's. A declared metric nobody computed is a failing move, not a skipped
one. A regression landing in a metric's noise band returns `repeat`, so a boundary example
that flakes costs a rerun instead of a coin flip.

`GateReport.summary()` is the comparison a CI comment prints, naming each metric that moved
and what it was allowed. `GateReport.permits(digest)` is the promotion check: an alias may
move only to text with a passing result for that exact digest, because the same version label
over edited text is a different prompt.
